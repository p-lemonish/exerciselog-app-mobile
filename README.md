# ExerciseLog App (Mobile Frontend)

A React Native + Expo mobile application for tracking workouts, planning exercises, and viewing progress.

## Features

- **User Authentication** – Login/Register with JWT-based auth and secure token storage (using `expo-secure-store`).  
- **Workout Planning** – Create custom exercises, plan workouts, and edit them at any time.  
- **Progress Tracking** – Log sets/reps/weights and review progress.  
- **Dark/Light Theme** – Automatically switches based on the device’s theme (or can be customized).  
- **React Native Paper** – Provides a consistent Material Design UI framework with theming support.

## Technologies

- **React Native** / **Expo** – Core mobile development platform.  
- **React Navigation** – Native stack navigation for screen transitions.  
- **React Native Paper** – UI component library, used for theming, buttons, text inputs, etc.  
- **Axios** – HTTP client for calling the backend API.  
- **TypeScript** – Strongly typed development for reliability and maintainability.  
- **SecureStore** – Storing JWT tokens securely on the device.
